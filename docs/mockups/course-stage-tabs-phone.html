Stage tabs on a phone

The stage page has five tabs: Instructions, Hints, Solution, Concepts and Last run. On a 375 px screen they do not fit in one row. Today the row scrolls sideways with its scrollbar hidden, so Concepts and Last run sit off-screen with nothing to say they are there. Three ways to show them. Tap a tab in B or C to try it.

A · today

One row, scrolls sideways

Concepts and Last run are cut off at the right edge. Nothing shows that the row scrolls. It also uses an underline for the active tab.

Recommendation: C. It keeps the header the same height as today, shows all five at once and puts each tab's state (hints opened, concepts read, last result) where it is useful on a phone. B is the safer change if you want the full labels. Both apply below 640 px only; the desktop tabs stay as they are. Nothing is built until you pick one.
