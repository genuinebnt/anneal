Compiler error · E0502

Changing something that is still being read

While a shared reference is still in use, the value it points into cannot be changed. The change could move or remove what the reference sees.

A small example, from another setting

let mut names = vec![String::from("a")];
let first = &names[0];
names.clear();          // E0502
println!("{first}");

Ways out, and when each fits

Finish reading first.

When the later change does not need the reference.

Keep an owned value or a position instead.

When what you need is small, or can be found again.

Borrow separate parts.

When the read and the change touch different data.
