# Interview Questions

Common Rust conceptual questions and coding questions (lists, trees, tries, caches, concurrency, systems design) answered as runnable recipes with Rust-specific pitfalls and follow-ups.

Run any recipe from the `cookbook/` directory: `cargo run --release --example <name>` (the name is the file name without `.rs`). Each file starts with a header: what it shows, `LEVEL`, `COMMON USES` and `Read:` links.

15 examples.
