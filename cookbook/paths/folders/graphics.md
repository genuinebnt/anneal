# Chapter `graphics`: suggested reading order

Ordered simple -> intermediate -> advanced (then alphabetical). Skim `Use in:` and `COMMON USES` in each header first. Cross-chapter order is in [the tracks](../tracks/).

| # | Recipe | Level | What it is |
|---|---|---|---|
| 1 | [`fractals_noise_automata`](../../examples/graphics/fractals_noise_automata.rs) | intermediate | generative graphics: fractals, noise, L-systems, cellular automata, reaction-diffusion, contours. |
| 2 | [`image_processing`](../../examples/graphics/image_processing.rs) | intermediate | classic image processing: convolution, edges, histograms, dithering, resampling, colour spaces, alpha. |
| 3 | [`lines_curves_fills`](../../examples/graphics/lines_curves_fills.rs) | intermediate | 2D drawing primitives: lines, circles, fills, Bezier and Catmull-Rom curves, SDFs, bitmap text. |
| 4 | [`png_ppm_writer`](../../examples/graphics/png_ppm_writer.rs) | intermediate | write and read images without crates: PPM (P6) and a minimal PNG encoder + decoder, sRGB, ASCII preview |
| 5 | [`vec3_matrix_quaternion`](../../examples/graphics/vec3_matrix_quaternion.rs) | intermediate | 3D math from scratch: Vec3, Mat4, projections, quaternions, gimbal lock, ray intersections |
| 6 | [`software_rasterizer`](../../examples/graphics/software_rasterizer.rs) | advanced | a complete software rasterizer: transforms, near-plane clipping, edge functions, z-buffer, shading, textures. |
