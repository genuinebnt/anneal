# cb-crate-tour

Popular external crates by example. Each file is a self-checking program: it asserts its claims and exits non-zero if one fails.
This is a separate workspace member so that these dependencies stay out of the cookbook's root manifest.

- Run one example: `cargo run --release -p cb-crate-tour --example NAME`
- Run all of them as tests: `cargo test -q --release -p cb-crate-tour`
- Benchmark (recipe 1117): `cargo bench -p cb-crate-tour --bench crate_tour_bench -- --quick`

The versions below are the requirements declared in each file's `CRATES:` header line. `Cargo.lock` in the cookbook root
records the exact versions that were built.
